# FLOKHOME HA Add-ons

Home Assistant Add-on repository.

## Install

Settings → Add-ons → Add-on Store → ⋮ → Repositories → add:
`https://github.com/FLOKHOME/ha-addons`

## Add-ons

| Add-on | Description |
|---|---|
| [LaCrosse 2 MQTT](./lacrosse2mqtt/) | LaCrosse IT+ sensors (via LaCrosseGateway) to MQTT with HA-Discovery — without FHEM |
